Help & Support

If you encounter any issues while using the admin page, here are some steps you can take:

  • Login Issues: Ensure you are using the correct username and password. If you have forgotten your password, click on the "Forgot Password" link on the login page.
  • Navigation: Use the navbar to access different sections of the admin portal.
  • Registration: For registering new students, navigate to the "Register New Student" section from the homepage.
  • Technical Support: Contact the IT department if you experience any technical difficulties.

For more detailed support, please contact our technical team.
